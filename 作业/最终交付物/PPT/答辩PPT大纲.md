### Slide 9 | Live Demo (2:00) 🎬核心

**标题**：现场演示

```
演示内容：
1. SSH 登录 VM-02 (openEuler ARM)
   → uname -m → aarch64

2. 检查容器状态
   → docker ps (7个容器全部 UP)

3. 浏览器访问博客
   → https://192.168.20.10
   → 展示首页、文章列表

4. 发布一篇测试文章 (Markdown + 代码块)
   → 草稿 → 提交审核 → 审核员通过 → 前台可见

5. 数据持久化验证
   → docker rm -f mysql → docker compose up -d mysql
   → 博客仍然正常，文章不丢失

6. 监控大盘展示
   → Grafana: CPU/内存/容器状态实时图表
```

## 答辩策略建议

### 时间分配
- Slide 1-4 (项目背景+目标+团队)：3 分钟
- Slide 5-8 (架构+技术栈)：4 分钟

- Slide 10-14 (运维+性能+安全)：3 分钟
- Slide 15-18 (总结+收获+Q&A)：3 分钟

### 关键技巧
1. **Live Demo 提前准备好**：提前打开终端和浏览器，避免现场等待
2. **突出3个亮点**：国产化→可复制→运维完备
3. **准备好降级方案**：如果网络不好，播放录屏备用
4. **准备FAQ**：导师可能问"ARM兼容性""故障处理""为什么要容器化"
5. **每个成员都上场**：各自讲自己负责的部分

### 预计FAQ

| 问题 | 回答要点 |
|------|---------|
| ARM架构兼容性如何？ | Halo/MySQL/Nginx/Prometheus都有ARM64官方镜像，已验证 |
| 为什么不用K8s？ | POC阶段单机够用，Compose更简单；生产可迁移到K8s |
| 数据安全保障？ | HTTPS+网络隔离+操作审计+每日备份+快照 |
| 遇到Docker Hub拉不下来怎么办？ | 阿里云镜像加速 + 私有Registry + 离线镜像包 |
| 如果系统崩了最快多久恢复？ | 快照回滚5分钟 + 备份恢复30分钟 |
