## 快速开始

```bash
# 1. 将运维脚本/ 拷贝到 VM-02 的 /opt/blog-platform/
cd /opt/blog-platform

# 2. 一键部署
chmod +x deploy.sh backup.sh
./deploy.sh

# 3. 设置自动备份
crontab -e
# 添加: 0 2 * * * /opt/blog-platform/backup.sh

# 4. 访问验证
curl -k https://localhost
```
