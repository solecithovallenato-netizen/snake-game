## 1. 文档说明

### 1.1 目的

本文档基于客户（政务信息中心）的《业务需求规格说明书 BRD》，将"业务语言"转化为"技术语言"，形成技术团队可实施、可测试、可验收的详细需求规格。

### 1.2 读者

- 架构师：用于系统设计参考
- 实施工程师：用于环境搭建和应用部署
- 测试工程师：用于编写测试用例和验收
- 客户技术接口人：用于需求确认和验收签字

### 1.3 术语

| 术语 | 全称 | 说明 |
|------|------|------|
| POC | Proof of Concept | 概念验证，验证技术方案的可行性 |
| FC | FusionCompute | 华为虚拟化平台 |
| ARM | Advanced RISC Machines | 鲲鹏处理器架构（aarch64） |
| BRD | Business Requirements Document | 业务需求文档 |
| SRS | Software Requirements Specification | 软件需求规格说明书 |

## 2. 功能需求（与 BRD 逐条对应）

### 2.1 基础设施需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|
| **SRS-INF-01** | BR-INF-01 | 在 FusionCompute 上创建集群 BlogOps-Cluster，主机为鲲鹏 TaiShan 200；创建 2 台 VM，规格 2vCPU/4GB/40GB 系统盘，操作系统 openEuler 22.03 LTS SP2 | FC 界面集群状态"正常"；VM 运行中；`uname -m` 显示 aarch64 |
| **SRS-INF-02** | BR-INF-02 | 划分 VLAN 10（管理网 192.168.10.0/24）和 VLAN 20（业务网 192.168.20.0/24）；安全组仅开放 22/80/443 | 跨 VLAN 互通测试通过；管理网无法直接访问业务网数据库端口（3306） |

### 2.2 容器平台需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|
| **SRS-PLT-01** | BR-PLT-01 | 安装 Docker CE 24.x，配置 systemd 自启动；所有应用组件（博客、数据库、代理）均以容器方式运行 | `docker version` Server 版本 ≥24.0；`docker ps` 显示所有业务容器 |
| **SRS-PLT-02** | BR-PLT-02 | 部署私有镜像仓库（Registry 或 Harbor）；生产环境禁止直接从 Docker Hub 拉取 | `docker push/pull` 私有仓库测试通过；部署脚本中镜像地址指向内网仓库 |

### 2.3 应用功能需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|
| **SRS-APP-01** | BR-APP-01 | 部署 Halo v2.x（国产开源博客），通过 Docker Compose 编排；支持 Markdown 写作、代码高亮、文章分类、标签管理、全文检索、评论功能 | 浏览器访问 `http://<业务IP>` 显示首页；发布含代码块文章前端渲染正常；搜索框输入关键词返回结果 |
| **SRS-APP-02** | BR-APP-02 | 博客后台配置审核工作流：文章默认状态为"草稿"；审核员账号可执行"通过/驳回"操作；通过后前台可见 | 非管理员发布文章前台不可见；审核员点击"通过"后前台刷新可见 |
| **SRS-APP-03** | BR-APP-03 | MySQL 8.0 容器数据持久化至宿主机 `/data/mysql`；博客上传文件持久化至 `/data/halo` | 执行 `docker rm -f mysql` 后重建容器，数据不丢失；宿主机目录存在数据文件 |

### 2.4 安全需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|
| **SRS-SEC-01** | BR-SEC-01 | Nginx 容器监听 80/443；80 端口强制跳转 443；配置 SSL 证书（POC阶段使用自签名证书） | `curl -I http://<IP>` 返回 301；`curl -k https://<IP>` 返回 200；浏览器访问显示锁图标 |
| **SRS-SEC-02** | BR-SEC-02 | MySQL 端口 3306 仅绑定业务网 IP（192.168.20.x）；安全组拒绝管理网段访问 | 从管理网 VM 执行 `telnet <DB_IP> 3306` 连接失败；业务网 VM 连接成功 |
| **SRS-SEC-03** | BR-SEC-03 | 配置审计日志：SSH 登录记录至 `/var/log/secure`；操作命令记录至 `/var/log/audit`；保留 90 天 | `last` 命令显示登录记录；`ausearch` 可检索历史命令；日志文件存在且符合保留策略 |

### 2.5 运维需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|
| **SRS-OPS-01** | BR-OPS-01 | 部署 Prometheus + node_exporter + cAdvisor；Grafana 导入容器监控大盘，展示 CPU/内存/磁盘/网络/容器状态 | Prometheus Targets 全部 UP；Grafana 可查看趋势图；容器重启后监控自动恢复 |
| **SRS-OPS-02** | BR-OPS-02 | 编写 backup.sh：每日 02:00 执行 mysqldump，备份压缩至 `/data/backup/backup_YYYYMMDD_HHMMSS.sql.gz`，保留 7 天 | `crontab -l` 显示定时任务；`/data/backup/` 存在 7 天内备份文件；恢复脚本可恢复完整数据 |
| **SRS-OPS-03** | BR-OPS-03 | 编写 deploy.sh：在全新 openEuler VM 上 30 分钟内完成全量部署（含 Docker 安装、镜像拉取、服务启动） | 企业老师现场计时；从执行脚本到首页可访问 ≤30 分钟 |

### 2.6 文档需求

| SRS 编号 | 对应 BRD | 需求描述（技术化） | 验收标准 |
|----------|----------|-------------------|---------|

## 3. 非功能需求（量化）

## 附录：BRD 到 SRS 转化法则

### 法则1：从"形容词"到"数字"

| BRD（业务语言） | SRS（技术量化） |
|----------------|---------------|
| "页面打开要快" | 页面平均响应时间 ≤3 秒（95分位） |
| "同时支持不少人访问" | 50 并发，错误率 0%，TPS ≥ 20 |
| "系统要稳定" | 可用率 ≥99.9% |
| "出故障快速恢复" | RTO ≤30 分钟 |
| "数据能找回" | RPO ≤24 小时 |

### 法则2：从"目标"到"动作+验证"

| BRD（目标） | SRS（动作+验证） |
|------------|-----------------|
| "建立国产化基线" | FC创建集群+2台VM（openEuler ARM），`uname -m` 输出 aarch64 |
| "验证容器化交付" | `docker compose up -d` 一键启动，`docker ps` 显示所有容器 |
| "形成可复用模板" | `deploy.sh` 在30分钟内部署全新环境 |
