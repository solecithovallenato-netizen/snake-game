## 1. 文档概述

本手册面向实施工程师和运维人员，详细描述政务数字门户平台 POC 的完整部署流程。从零开始，按照本手册操作，可在 30 分钟内完成全量部署。

### 1.1 前置条件

- FusionCompute 平台可访问
- openEuler 22.03 LTS SP2 ARM64 镜像已上传至 FC
- 具备 root 权限的 VM 账号
- 网络已按设计划分（VLAN 10 管理网 + VLAN 20 业务网）

### 1.2 部署概览

```
Step 1: FusionCompute 创建 VM      (~10 min)
Step 2: 操作系统初始化              (~5 min)
Step 3: Docker 环境安装             (~5 min)
Step 4: 一键部署应用                (~8 min)
Step 5: 验证                       (~2 min)
────────────────────────────────────────
总计:                               约 30 分钟
```

## 2. 第一步：FusionCompute 创建虚拟机

### 2.1 创建集群

1. 登录 FusionCompute Web 管理界面
2. 进入「资源池」→「集群」→「创建集群」
3. 集群名称：`BlogOps-Cluster`
4. 选择主机：鲲鹏 TaiShan 200
5. 开启 HA 和 DRS

![创建集群]（截图：FC集群创建页面）

### 2.2 创建虚拟机

创建 2 台 VM，配置如下：

| 参数 | VM-01（管理节点） | VM-02（业务节点） |
|------|------------------|-------------------|
| 名称 | dmp-mgmt-01 | dmp-svc-01 |
| vCPU | 2 | 2 |
| 内存 | 4 GB | 4 GB |
| 系统盘 | 40 GB | 40 GB |
| 数据盘 | — | 100 GB（thin provision） |
| 操作系统 | openEuler 22.03 LTS SP2 | openEuler 22.03 LTS SP2 |
| 架构 | ARM64 (aarch64) | ARM64 (aarch64) |
| 网络 | VLAN 10 (管理网) | VLAN 20 (业务网) |
| IP 地址 | 192.168.10.10 | 192.168.20.10 |

### 2.3 配置安全组

| 方向 | 来源 | 目的端口 | 协议 | 动作 |
|------|------|---------|------|------|
| 入站 | 0.0.0.0/0 | 80, 443 | TCP | 允许 |
| 入站 | 192.168.10.0/24 | 22 | TCP | 允许 |
| 入站 | 192.168.20.0/24 | 3306 | TCP | 允许 |
| 入站 | 0.0.0.0/0 | 3306 | TCP | 拒绝 |
| 入站 | 0.0.0.0/0 | 全部 | ALL | 拒绝 |

### 2.4 验证

登录 VM，执行以下命令验证：

```bash
# 确认 ARM 架构
uname -m
# 期望输出: aarch64

# 确认操作系统版本
cat /etc/openEuler-release
# 期望输出: openEuler release 22.03 LTS SP2

# 确认 IP 地址
ip addr show
# 期望: 192.168.20.10 (业务节点) 或 192.168.10.10 (管理节点)
```

## 3. 第二步：操作系统初始化

SSH 登录到 VM-02（业务节点），以下操作需 root 权限：

```bash
# 1. 更新系统
dnf update -y

# 2. 安装必要工具
dnf install -y vim wget curl net-tools telnet bash-completion

# 3. 设置时区
timedatectl set-timezone Asia/Shanghai

# 4. 设置主机名
hostnamectl set-hostname dmp-svc-01

# 5. 关闭 SELinux（POC环境简化）
setenforce 0
sed -i 's/SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config

# 6. 配置防火墙（或使用 FC 安全组替代）
systemctl stop firewalld
systemctl disable firewalld

# 7. 创建数据目录
mkdir -p /data/{mysql,halo,backup,nginx/ssl}
```

---

## 4. 第三步：Docker 环境安装

```bash
# 1. 安装 Docker CE 24.x
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 2. 验证版本
docker version
# 期望: Server Version ≥ 24.0

# 3. 配置镜像加速（阿里云）
mkdir -p /etc/docker
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": ["https://xxxxxxxx.mirror.aliyuncs.com"],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  },
  "storage-driver": "overlay2"
}
EOF

# 4. 启动 Docker
systemctl daemon-reload
systemctl enable docker --now
systemctl status docker
# 期望: active (running)

# 5. 验证 Compose
docker compose version
# 期望: Docker Compose version v2.20+
```

## 5. 第四步：部署应用（deploy.sh 一键部署）

### 5.1 获取部署包

将以下文件传输到 VM-02 的 `/opt/blog-platform/` 目录：

| 文件 | 说明 |
|------|------|
| docker-compose.yml | 容器编排文件 |
| nginx.conf | Nginx 配置 |
| deploy.sh | 一键部署脚本 |
| backup.sh | 备份脚本 |
| prometheus.yml | Prometheus 配置 |
| grafana-dashboard.json | Grafana 大盘配置 |

### 5.2 执行一键部署

```bash
cd /opt/blog-platform
chmod +x deploy.sh backup.sh
./deploy.sh
```

**deploy.sh 会自动执行**：
1. 检查 Docker 环境
2. 拉取所有镜像（Halo、MySQL、Nginx、Prometheus、Grafana）
3. 生成 SSL 自签名证书
4. 创建必要的目录
5. 启动所有容器（docker compose up -d）
6. 等待 MySQL 就绪
7. 初始化 Halo 数据库
8. 输出访问地址

## 7. Halo 初始化指南

首次访问博客后台时需要完成初始化：

1. 浏览器打开 `https://192.168.20.10/admin`
2. 设置管理员账号（用户名/密码/邮箱）
3. 设置站点标题：「政务数字门户平台」
4. 选择主题（推荐默认主题或选用政企风格主题）
5. 创建必要的分类（如：技术文档、政策解读、工作动态等）
6. 创建审核员账号（用于审核工作流）

## 8. 常见问题

### Q1: Docker 镜像拉取失败/速度慢

**原因**：国内网络访问 Docker Hub 受限

**解决**：
```bash
# 方案A: 配置阿里云镜像加速
# 编辑 /etc/docker/daemon.json，添加 registry-mirrors

# 方案B: 使用离线镜像包
docker load -i halo-v2.x-arm64.tar
docker load -i mysql-8.0-arm64.tar
```

### Q2: 容器启动后无法访问

```bash
# 检查容器日志
docker logs nginx
docker logs halo
docker logs mysql

# 检查端口监听
netstat -tlnp | grep -E '80|443|8090|3306'

# 检查安全组
# 确认 FC 安全组已开放 80/443
```

### Q3: MySQL 连接被拒绝

```bash
# 检查 MySQL 是否绑定正确网卡
docker exec mysql netstat -tlnp | grep 3306

# 检查是否只能从业务网访问
# 从管理网 VM 测试:
telnet 192.168.20.10 3306
# 应连接失败！
```

### Q4: HTTPS 显示不安全警告

**原因**：POC 阶段使用自签名证书

**解决**：浏览器点击"高级"→"继续访问（不安全）"即可。生产环境可更换 Let's Encrypt 证书。
