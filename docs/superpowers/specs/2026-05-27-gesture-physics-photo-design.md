# Gesture Physics Photo — Design Spec

**日期**: 2026-05-27
**状态**: 设计完成

## 概述

单文件 HTML5 Web 应用。用户上传任意照片 → AI 分割物体 + 估计深度 + 识别材质 → 在 3D 物理场景中用手势"拎起"物体、扔出、旋转，松手后物体受真实物理（重力/碰撞/弹性/摩擦/惯性）影响自然掉落。UI 采用 Apple Liquid Glass 风格。

## 核心体验

- 摄像头捕捉双手，3D 手骨架叠加在场景中
- 主手（金色骨架）捏合抓取物体，张开放下，可扔可转
- 辅手（冷蓝色骨架）控制场景：旋转/缩放/平移/重置
- 每个物体有独立物理属性（质量/弹性/摩擦），由 AI 识别材质决定
- 物体松手后掉回场景，有碰撞堆叠，不破坏背景

---

## 系统架构

四层结构：

```
🖐 输入层        →  Webcam 手势 + 用户上传图片
🧠 AI 处理层     →  SAM 分割 + Depth 深度 + MiMo 语义 + LaMa 背景修复
⚙️ 物理引擎层    →  Cannon-es（重力/碰撞/约束/材质参数）
🎨 渲染层        →  Three.js WebGL + 手势骨架叠加 + 液态玻璃 UI
```

### 数据流

```
用户上传图片
  → SAM 分割 → N 个 mask（轮廓/包围盒/面积/中心点）
  → Depth Anything V2 → 深度图（每像素深度值）
  → MiMo-V2.5-Pro → 材质类型 + 物体语义 + 碰撞体形状选择
  → LaMa → 背景空洞填充
  → 每个物体 = { 3D mesh, 纹理, 物理体, 材质参数 }
  → 返回 JSON 给前端，缓存（图片 hash）

每帧循环：
  → MediaPipe Hands → 双手 21 个关键点 3D 坐标
  → 手势识别 → 捏合=抓取 / 张开=释放 / 其他手势
  → Cannon-es step() → 更新物体位置/姿态/碰撞
  → Three.js render() → 输出画面
```

## AI 管线

### 部署方式：云端混合（方案 C）

AI 推理在云端做一次（质量最高），结果 JSON 回传后缓存。物理交互完全在浏览器本地，零延迟。

### 模型清单

| 模型 | 任务 | 部署 |
|------|------|------|
| SAM (Segment Anything) | 物体分割 → mask | 云端 GPU |
| Depth Anything V2 | 单目深度图 | 云端 GPU |
| MiMo-V2.5-Pro | 材质识别 + 物体分类 + 碰撞体选择 + 场景理解 | 云端 API |
| LaMa | 背景空洞填充 | 云端 GPU |

### MiMo 的角色

作为"大脑"做语义理解：
- 识别每个物体的材质（木头/金属/布料/玻璃/塑料/纸张等）
- 判断物体类型（球形/方形/瓶罐/不规则/扁平）→ 选择视觉+碰撞策略
- 场景级理解：物体间的遮挡关系、哪些物体在哪些物体上面

像素级工作（分割、深度）交给专用模型。

### 后端接口

```
POST /api/analyze
Body: multipart/form-data { image }
Response: {
  objects: [{
    id: number,
    mask: number[][],        // 轮廓多边形顶点
    bbox: [x,y,w,h],
    depth_mean: number,
    depth_range: number,     // 厚度
    material: "wood"|"metal"|"fabric"|"glass"|"plastic"|"paper",
    mesh_type: "sphere"|"box"|"cylinder"|"extruded"|"flat",
    physics: {
      density: number,       // kg/m³
      restitution: number,   // 弹性系数
      friction: number       // 摩擦系数
    }
  }],
  background_url: string,   // LaMa 修复后的背景图
  depth_map_url: string     // 原始深度图
}
```

## 物理引擎：Cannon-es

### 选型理由

- 轻量（~150KB），与 Three.js 集成成熟
- 同一场景物体数量有限（5-30），不需要 Rapier 级性能
- 支持全部所需：重力、碰撞检测、摩擦、弹性、Point-to-Point 约束

### 材质参数映射

| 材质 | 密度 (kg/m³) | 弹性系数 | 摩擦系数 | 手感 |
|------|-------------|---------|---------|------|
| 木头 | 600 | 0.3 | 0.6 | 温润有重量 |
| 金属 | 7800 | 0.05 | 0.25 | 很沉、掉落快 |
| 布料 | 200 | 0.02 | 0.9 | 轻飘飘 |
| 玻璃/陶瓷 | 2500 | 0.01 | 0.3 | 滑、易碎感 |
| 塑料 | 1000 | 0.4 | 0.5 | 轻而有弹性 |
| 纸张 | 700 | 0.1 | 0.7 | 飘落有翻转 |

### 抓取机制

- **捏合判定**：拇指尖 ↔ 食指尖距离 < 2cm（基于 MediaPipe 3D 坐标）
- **抓取**：手和物体间建立 Cannon-es LockConstraint（Point-to-Point）
- **释放**：手指间距变大 → 删除约束 → 物体保留当前线速度和角速度自由落体
- **旋转传递**：抓取时手腕旋转传递给物体角速度

## 手势交互

### 双手分工

| | 主手（右手/惯用手） | 辅手（左手） |
|---|---|---|
| 骨架颜色 | 暖金色 | 冷蓝色 |
| 角色 | 物理交互手 | 场景控制手 |
| 捏合 | 抓起物体 | 旋转场景视角 |
| 张开 | 放下/扔出物体 | — |
| 握拳 | 猛拉物体 | 平移场景 |
| 两指缩放 | — | 拉近/拉远场景 |
| 捏合+转腕 | 旋转手中物体 | — |
| 挥手 | — | 重置所有物体 |
| 双手配合 | — | 双手捏合拉开=缩放；双手旋转=旋转场景 |

### 手势判定

- 捏合：thumb_tip ↔ index_tip < 2cm（3D 空间距离）
- 张开：5 指伸展度 > 70%（指尖到手掌中心的距离比）
- 握拳：5 指伸展度 < 20%
- 两指缩放：食指+中指间距离变化率
- 挥手：手腕 X 轴速度 3 次过零

### 距离反馈

1. **距离光环**：手指靠近物体时光环亮度/粗细渐变
2. **3D 手骨架**：半透明玻璃材质，Z 深直接可视
3. **接触粒子**：手指碰到物体时爆发金色粒子
4. **深度阴影**：手在物体上方时投射阴影

## 3D 场景重建

### 视觉 Mesh（精细）

1. **提取 mask 轮廓**：自适应采样（32-256 点）
2. **三角剖分**：earcut/CDT 对轮廓做三角剖分 → 前面板
3. **深度位移**：顶点 Z = depth × scale，内部采样深度平滑变化
4. **背面+侧面缝合**：前面板向后挤出 → 背面 + 侧面三角形带
5. **UV 映射**：前面板 UV = 原图像素坐标归一化；侧面用邻近色

### 物理碰撞体（简化）

mask 轮廓简化到 ≤16 顶点，使用 Cannon-es ConvexPolyhedron。

### 不同物体类型的处理

| 类型 | 视觉处理 | 碰撞体 |
|------|---------|--------|
| 球/圆形 | mask 拟合椭圆，纹理映射椭球面 | Sphere |
| 方形 | mask bbox，6 面贴图 + 微倒角 | Box |
| 瓶/罐/杯 | mask 纵向分层圆柱段拼接 | 多段 Cylinder 复合 |
| 不规则 | 完整 mask 挤出 + 深度位移 | 简化 ConvexHull ≤16顶点 |
| 扁平 | 薄片挤出 + 翘曲效果 | 薄 Box |

MiMo 判断物体类型 → 选择对应策略。

### 场景分层

- Z=far：背景平面（LaMa 修复后），静态不可交互
- Z=0~3：物体层，深度决定 Z 轴位置
- Z=-N：手交互层，手骨架在此操作

## UI 设计：Liquid Glass

### 设计语言

- 通透感：`backdrop-filter: blur(20px) saturate(180%)`
- 厚度感：多层 border + inset shadow 模拟玻璃厚度
- 深邃底：深色基底 #0a0a0f，玻璃悬浮感
- 流动感：hover 微动，颜色随场景变化

### 核心 CSS

```css
.glass-panel {
  background: rgba(18, 16, 24, 0.45);
  backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 16px;
  box-shadow:
    0 8px 32px rgba(0, 0, 0, 0.4),
    inset 0 1px 0 rgba(255, 255, 255, 0.06),
    inset 0 0 0 1px rgba(255, 255, 255, 0.03);
}
```

### UI 组件

| 组件 | 位置 | 说明 |
|------|------|------|
| 底部工具栏 | 底部居中 | 上传/重置/帮助，药丸形 |
| 物体信息卡 | 跟物体 | 显示材质/重量/状态 |
| 交互提示 | 中上浮动 | "捏合抓取" "松手释放" |
| 环形进度 | 中央 | AI 处理进度 |
| 摄像头小窗 | 右下角 | 手势镜像预览 |
| 帮助引导 | 首次全屏 | 手势教程卡片 |

## 技术栈

### 前端（单文件 HTML）

| 层 | 技术 | 用途 |
|----|------|------|
| 渲染 | Three.js 0.157+ (CDN) | 3D 场景、mesh、骨架、粒子 |
| 物理 | Cannon-es (CDN) | 重力/碰撞/约束 |
| 手势 | MediaPipe Hands (CDN) | 21 点手部关键点、双手追踪 |
| 图像处理 | Canvas 2D | mask 轮廓、纹理裁剪、earcut |
| UI | 原生 CSS | Liquid Glass 面板 |
| 部署 | GitHub Pages | 静态托管 |

### 后端（AI 推理）

- 腾讯云 SCF / 阿里云 PAI + GPU
- 四个模型串行调用 → 一次返回完整结果
- 图片 hash 缓存，避免重复推理

## 成功标准

1. 用户上传任意照片，30 秒内完成 AI 分析并显示可交互场景
2. 双手手势流畅追踪，延迟 < 50ms
3. 物体抓取/释放/碰撞堆叠有真实物理手感
4. 同张图片第二次打开秒开（缓存命中）
5. 移动端降级可用（触屏替代手势）
